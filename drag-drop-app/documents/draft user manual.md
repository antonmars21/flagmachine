# Flag Machine + Finish Sheet — User Manual (draft)

## Quick guide: a basic race start to finish

**Set up**

1. On the **Race Officer** page, drag the class flag for each start into a start event. At least 1 class flag; 1 optional signal flag; max 3 flags per event.
2. Open a **Finish Sheet**, click **Sailor Registry** and tick the sailors signed on today, then close the registry. **Do NOT start the race from the finish sheet** — go back to **Race Officer Control**.

**Start**

3. On the Race Officer page, click **Start**. The countdown runs; each start fires when its last flag row completes.
4. Open **Finish Sheet 1** and **Finish Sheet 2** — one browser window each — and drag one onto each screen. One or two scorers can work at the same time.

**During the race**

5. **Lap:** when a boat crosses, press its blue **+ Lap** button — press as they cross, we want reasonably accurate times.
6. **Finish:** when a boat finishes, tick its white box.
7. Made a mistake? Press **Undo** to remove the last capture on that station.

**Finish and reset**

8. When the last boat is in, click **End Race**.
9. Click **Export CSV** and keep the downloaded file (it is named with the series and date, ready for Sailwave).
10. Click **Reset Finish Sheet**. If the fleet changed for the next race, clear the ticks in the Sailor Registry. Then on the Race Officer page click **Reset**.

Ready for the next race.

## Turning this draft into a manual — easy options

Recommended for this club: keep this file as the master copy (markdown), then produce the printable manual with screenshots using one of these:

| Tool | What it does | Effort |
|---|---|---|
| **Scribe** or **Tango** (free Chrome extension) | Records your clicks and writes the manual FOR you, with annotated screenshots of every step. Do one practice race, get a visual guide. | Easiest |
| **Pandoc** (one command) | Turns this .md straight into Word or PDF: `pandoc "draft user manual.md" -o manual.docx` | Easy, no screenshots |
| **VS Code "Markdown PDF"** extension, or dillinger.io | Paste the markdown, export PDF. Nothing to install (dillinger) or one extension (VS Code). | Easy |
| **Word / Google Docs** | Paste and format by hand; good if you want full control. | Manual work |
| **MkDocs / GitBook** | Turns markdown into a website with a table of contents — best if the manual lives on the club laptop for reading on screen. | More technical |

Best fit for retired-sailor users: generate the manual once with **Scribe** while clicking through a practice race (it captures the actual screens with arrows on the buttons), then save the result as a PDF and print a copy for each scorer station.
